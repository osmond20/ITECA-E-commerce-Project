This is the project completed during for ITECA3-34 course. It comprised of building an e-commerce application. The technology stack requirements are:
- HTML
- CSS (please refer to style guide for styling)
- JS
- PHP
- MySQL

The website integrations and plugins that contributed to building this application are:
- FormSpree
- PayFast
- PHPMailer (for sending emails via Gmail)

Platform used for testing are:
- TestSprite for backend testing and frontend testing
- Lighthouse in DevTools
